# COLR residual store references

Raw COLR tables generated by HarfBuzz 0bd344a29 from the synthetic font in
`color_store_test::source`, with all glyphs, retained IDs, the .notdef
outline, all layout features and names, and `--instance=wght=650`.

Two source VarData groups contain rows over positive weight and negative
width regions. The width coefficients are `[1000, 1000, 0, -2000]` and
`[-2000, 1000]`. Weight coefficients are all 100 except the first row
of the second group, which is -100. Three variable translations reference
all six rows; their variable solid children exercise repeat-last mapping.
The `constant` case zeros all width coefficients.

The mapped case compacts six rows to two and maps the zero row to the
no-variation sentinel. The implicit case preserves six consecutive rows.
The constant case removes the store and retains a sentinel index map.
Tests compare decoded tables and also complete partial instances, including
subsetting between instancing steps, at three width locations.

The three `*-regions.bin` files contain HarfBuzz's raw variation region
lists after restricting `test_glyphs-glyf_colr_1_variable.ttf` to
`ROTA=134.997:269.995:404.992`, `APH1=-0.75:-0.5:-0.25`, and
`APH2=-0.75:-0.5:-0.25`. They exercise ordering surviving source regions
before newly rebased ones.
